## Проверка выполнения и собственная реализация

Отдельная проверка web-запроса **без OAuth и cookies** получила HTTP 200, codec mp3, transport raw и ссылку на файл. Это подтвердило только выдачу MP3, а не его полную длительность. Пользователь обнаружил 15/30-секундные фрагменты без поля preview. Поэтому успешный ответ этого метода больше не считается доказательством полного файла: движок сверяет фактическую длительность с durationMs каталога перед сохранением. Скрипт `scripts/probe-web.mjs` читает лишь первые байты и не является проверкой полной композиции.

VOLNA реализует этот протокол собственными модулями `web-provider.ts`, `mp4-flac.ts`, `page-bridge.ts`. В неё не перенесены монетизация, чужие изображения, донат-ссылки или телеметрия исходного расширения. HMAC используется для подписи запроса web-клиента, не для расшифровки медиа. Ответы encraw, ключи шифрования, DRM, preview и посторонние CDN не принимаются.

Функции текстов используют сессию открытой страницы, если анонимный API отвечает 401. Текст сохраняется лишь при явной выдаче сервисом; при отказе остаётся видимое пояснение. Это ограничение, а не фиктивная доступность текстов для всего каталога.
